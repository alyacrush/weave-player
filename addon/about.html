Данные / Data

Плеер обращается к Twitch и серверам доставки видео; встроенный чат загружает сайт Twitch. Настройки хранятся локально. Передача отчётов исходному автору и его проверка обновлений отключены. Новый отчёт сохраняется только по нажатию пользователя и содержит минимальные сведения о версии.

The player connects to Twitch and media CDNs; embedded chat loads Twitch. Settings are stored locally. Upstream report submission and version checks are disabled. Diagnostic export is manual and local. No proxy has been added.

Full network and consent audit is pending before store publication.
