# Security reporting

Development preview. A private vulnerability-reporting channel is not yet configured.
Do not post credentials, exploitable secrets or raw diagnostic logs in public issues.
Before opening the repository publicly, the maintainer must configure a private
reporting channel (for example GitHub private vulnerability reporting).
Until then, use only an already-established private conversation with the maintainer.
No public support email address is declared by this project.

The initial fMP4 checkpoint inherited upstream report submission; do not use its
Send Report flow. Current development code removes that network submission and
exports only a local allowlisted report. Full network/data audit is ongoing.
